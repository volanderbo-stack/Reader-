# Зчитувач

Застосунок (PWA), який зчитує все з фото і відео: текст, таблиці, зображення з описами, QR-коди. Він зшиває частини в один документ і зберігає їх у бібліотеку з пошуком. Відео, які зчитати неможливо, позначаються слотами, і на їхнє місце записується твоє власне відео. Повний опис — у [ОПИС.md](ОПИС.md).

## Запуск

```bash
npm install
npm run dev
```

Відкрий адресу, яку покаже команда. Щоб працювала камера на телефоні в тій самій Wi-Fi мережі, запусти з https:

```bash
npm run phone
```

Браузер попередить про самопідписаний сертифікат: це нормально, підтверди перехід.

## Розпізнавання

- **Claude** (⚙ → ключ API) — повне зчитування: рукопис, таблиці, зображення, відео на сторінці, розумне зшивання частин.
- **Локально** (Tesseract) — без ключа і офлайн, але лише текст і QR-коди.

Усі дані зберігаються тільки в браузері на цьому пристрої (IndexedDB).

## Будова

| Файл | Що робить |
|---|---|
| `src/main.js` | екрани: бібліотека, нове зчитування, документ, налаштування |
| `src/recognize.js` | розпізнавання одного фото (Claude або Tesseract) + QR |
| `src/stitch.js` | зшивання частин без повторів |
| `src/video.js` | вибір чітких кадрів з відео, запис власного відео |
| `src/image.js` | обробка зображень, QR, різкість кадрів |
| `src/export.js` | експорт у Markdown (ZIP), DOCX, TXT |
| `src/db.js` | бібліотека в IndexedDB |
